frankG × cameron — standalone site
=================================

1. Unzip this folder.
2. Open index.html in a browser (double-click, or File → Open).

Keep the media/ folder and favicon.svg next to index.html.

Fonts load from Google Fonts when you are online. Offline, the site still
works with system serif/sans fallbacks.

To send conversation notes to an email instead of the clipboard,
open index.html and search for formatBrief — you can switch Send
to a mailto: link of your choosing.
